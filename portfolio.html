CC5Accessing data. Use a live API.

This chart loads fresh data from the World Bank API each time the page is opened.

How the API works

a. Base URL

https://api.worldbank.org/v2/ is the World Bank Indicators API (version 2). It is free and needs no API key.

b. Elements needed to call the data

  • Countries: country/ita;fra;esp;deu. Country codes go after country/, separated by semicolons.
  • Indicator: indicator/SP.DYN.CBRT.IN is the crude birth rate per 1,000 people.
  • Format: format=json. Without it, the API returns XML.
  • Page size: per_page=1000. The default page is much smaller, so this keeps all 264 records in one call.

c. Data returned

JSON: an array whose first item is metadata (pages, total, last updated) and whose second item is the list of records. Each record is one country-year, so the data are close to tidy. Country and indicator are nested objects, date is text, and the latest year (2025) is null. The chart reads the second item with "property": "[1]".

Full URL used in the chart

https://api.worldbank.org/v2/country/ita;fra;esp;deu/indicator/SP.DYN.CBRT.IN?format=json&per_page=1000

Source: World Bank, World Development Indicators (SP.DYN.CBRT.IN).
